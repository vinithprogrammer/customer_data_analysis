# 👨🏻‍💻 Customer Shopping Behavior Analysis

This project demonstrates an end-to-end **Data Analytics workflow** using customer shopping behavior data.
It covers data preparation, exploratory analysis, SQL-based analysis, and interactive visualization to generate meaningful business insights.

## 📌 Project Overview

The objective of this project is to analyze customer shopping behavior and identify trends that can help businesses improve **customer engagement, sales performance, loyalty, and marketing strategies**.

The project focuses on:

* 🐍 **Data Preparation & Exploratory Data Analysis (Python):** Clean, transform, and explore the raw customer dataset.
* 🗄️ **Data Analysis (SQL):** Store the cleaned data in a structured database and analyze customer segments, loyalty, and purchasing patterns.
* 📊 **Visualization & Insights (Power BI):** Create an interactive dashboard to identify important trends and business insights.
* 📑 **Report & Presentation:** Summarize findings and provide actionable business recommendations.

## ⚙️ How to Use This Project

### 1. Clone the repository

```bash
https://github.com/vinithprogrammer/customer_data_analysis.git
cd customer_data_analysis
```

### 2. Run the Python Notebook

Open:

`Customer_Shopping_Behavior_Analysis.ipynb`

The notebook covers:

* Data Import
* Data Exploration
* Data Cleaning
* Data Transformation
* Exploratory Data Analysis
* Loading the cleaned data into the SQL database

### 3. Perform SQL Analysis

Open:

`customer_behavior_sql_queries.sql`

Use the SQL queries to analyze:

* Customer segments
* Purchasing behavior
* Customer loyalty
* Product and category trends
* Purchase drivers

### 4. Open the Power BI Dashboard

Open:

`customer_behavior_dashboard.pbix`

The dashboard provides interactive visualizations to explore customer behavior and identify important business trends.

## 📈 Key Business Objectives

The analysis aims to help answer questions such as:

* Which customer segments contribute most to sales?
* What factors influence purchasing decisions?
* How do discounts affect customer purchases?
* Which product categories perform best?
* What factors are associated with repeat purchases?
* How can customer engagement and marketing strategies be improved?

## 🎯 Business Outcome

The project transforms raw customer shopping data into **actionable business insights** that can support better decisions related to:

* Customer engagement
* Marketing strategies
* Product strategies
* Sales performance
* Customer loyalty
